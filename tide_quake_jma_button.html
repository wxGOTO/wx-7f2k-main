注意

単体HTML版です。ブラウザの制限で気象庁ページを直接読み取れない場合は、プロキシ経由で再試行します。

潮位表は実測潮位ではなく、天文潮位の予測値です。「地震発生後の潮汐」では地震発生時刻より前の満潮・干潮を表示対象から外します。「指定日の潮汐」では地震発生時刻を無視して指定日だけを表示します。地震後の津波・副振動・気象要因による水位変化の判断には使えません。

潮回り（大潮・中潮・小潮・長潮・若潮）は tide736 API の moon.title を表示します。直接取得に失敗した場合は、tide736用プロキシ候補を上から順に試します。

tide736は気象庁・海上保安庁の公式サービスではありません。API停止・仕様変更・アクセス制限の可能性があります。
